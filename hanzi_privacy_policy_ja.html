1. はじめに

「漢字拆拆楽」（以下「本アプリ」または「当方」）をご利用いただきありがとうございます。本アプリは、漢字を画に分解する遊びを中心とした、個人開発・運営のオフラインパズルゲームです。

当方はお客様のプライバシーを重視し、適用される個人情報保護法令および本アプリを提供するアプリストアの規則に従って情報を取り扱います。

本ポリシーは、本アプリが取り扱う情報とその目的、利用する第三者サービス、お客様の権利、および安全管理について説明するものです。本アプリをダウンロード、インストール、起動、または継続して利用する前に、内容をよくお読みください。

2. 取り扱う情報

2.1 収集しない情報

アカウント登録は不要です。また、当方が運営するサーバーへ以下の情報をアップロードすることはありません。

  • 氏名、性別、生年月日、身分証番号、電話番号、メールアドレス
  • IDFA、IDFV、MAC アドレス、IMEI、端末シリアル番号などの端末識別子
  • GPS 位置情報または IP アドレス（購入や iCloud のため Apple が必要とする最小限のシステム通信を除く）
  • 連絡先、メッセージ、通話履歴、カレンダー、写真、動画、マイク録音、カメラ映像
  • SNS アカウントや識別可能な Apple ID 情報などの第三者アカウント情報

2.2 端末内で処理・保存する情報

次の情報は、お客様の端末または Apple ID に紐づく iCloud のみに保存され、当方が読み取ることはできません。

情報目的保存場所
ステージ進行状況、星、ベストタイム進行状況の復元とステージ画面への表示端末の Keychain、Application Support のバックアップ
コイン残高ヒントやスキップ時の表示・消費端末の Keychain、iCloud Key-Value Store による同一 Apple ID 端末間の同期
BGM・効果音の設定設定の保持端末の UserDefaults
購入状態コインパック購入の確認と反映Apple StoreKit が処理し、取引結果のみ一時的に本アプリへ返されます
これらの情報はお客様を識別する項目と紐づけられません。アンインストール後も、再インストール時にコイン残高を復元できるよう、一部の情報が iCloud に残る場合があります。第7条の方法で削除できます。

4. 第三者 SDK・サービス

名称提供者目的状態

Apple iCloud Key-Value StoreApple Inc.Apple ID を通じたコイン残高の同期有効

4.1 Apple のサービス

StoreKit、iCloud、Keychain は iOS のシステムサービスです。サービス提供中に Apple ID に関連する情報を Apple が処理する場合があります。この処理は Apple が管理し、開発者はアクセスできません。詳しくは Apple プライバシーポリシーをご覧ください。

4.2 Google Mobile Ads SDK

AdMob は依存関係に予約されていますが、現行版では初期化も呼び出しもされないため、データを収集・送信しません。将来有効化する場合、ATT 同意後の IDFA、端末モデル、OS バージョン、おおよその地域、広告操作などが処理される可能性があります。有効化前に本ポリシーを更新します。詳しくは Google プライバシーポリシーおよび Google Mobile Ads SDK の開示をご覧ください。

5. 保存・共有・移転

5.1 保存場所と期間

第2.2条の情報は、端末または Apple ID に紐づく iCloud に保存されます。当方はユーザーデータ用サーバーを運営しません。端末内の情報は、アプリの削除、該当する iCloud データの削除、または端末の消去まで保持されます。iOS の仕様により、一部の Keychain 情報はアンインストール後も残る場合があります。

5.2 共有・開示

当方がお客様の個人情報を積極的に共有、販売、移転することはありません。明示的な同意がある場合、法令や拘束力のある行政・司法手続により必要な場合、または本アプリ、利用者、公共の正当な権利を守るために必要な場合に限り開示します。

6. 情報の安全管理

  • コイン残高と進行状況は iOS Keychain とシステム暗号化で保護されます。
  • データ最小化の原則に従い、不要な権限を要求しません。
  • 開発者が運営するサーバーへ個人情報を送信しません。
  • 購入と iCloud 同期には Apple のシステムサービスと安全管理を利用します。

いかなるシステムも絶対に安全とはいえません。個人情報に関する事故が発生した場合は、適用法令に基づく報告・通知義務に従います。

7. お客様の権利

7.1 確認

コイン残高、ステージ進行状況、設定は本アプリ内で確認できます。本アプリは、それ以外の非表示の利用者プロフィールを保持しません。

7.2 削除

  • 本アプリをアンインストールすると、Application Support ファイルと UserDefaults が削除されます。Keychain 情報は残る場合があります。
  • iCloud データを削除するには、「iPhone の設定 → Apple ID → iCloud → アカウントのストレージを管理 → 漢字拆拆楽 → データを削除」を使用します。
  • 端末を消去すると、端末上のすべての情報が削除されます。

7.3 同意の撤回・苦情

利用を停止して情報を削除することで同意を撤回できます。撤回は、それ以前の適法な処理には影響しません。ご質問や苦情は第10条の連絡先へお寄せください。

8. お子様のプライバシー

本アプリは、お子様にも適した全年齢向けのパズルゲームです。お子様を識別する情報を収集せず、交流、チャット、ユーザー投稿機能もありません。コインパックのアプリ内購入があるため、保護者の方は iOS の「スクリーンタイム → コンテンツとプライバシーの制限 → 購入」を有効にすることをご検討ください。許可のない利用や購入を確認した保護者の方は、当方へご相談ください。

9. 本ポリシーの変更

本ポリシーを随時更新する場合があります。更新版は、バージョンと施行日を明記して同じ場所に掲載します。収集範囲の拡大、利用目的の変更、第三者 SDK の有効化など重要な変更については、アプリ内で分かりやすくお知らせします。
